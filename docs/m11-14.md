# M11-14 references and session compaction

Messages accept `@file:path` (optionally `#Lstart-Lend`) and `@diff` (or
`@diff --staged`). References are expanded inside the workspace before the
model context is assembled. File snippets are bounded to 8 KiB, diff snippets
to 16 KiB, and a message expands at most ten file references. Invalid paths and
missing files are surfaced in the run's user context; a clean or non-Git
workspace produces an explicit diff availability message.

Use `/compact` in `chat`, or run `cloud-harness compact --session SESSION_ID`,
to replace the visible history with a structured fast-model summary and the
latest five history records. The summary is saved as session memory, while
events and history rows remain available for audit and retrieval. Summaries are
bounded to 4 KiB and include an explicit truncation marker when needed.
